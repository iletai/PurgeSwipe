Spec — accessibility

  • Dynamic Type to AX5: rows grow, values move under title, buttons wrap label not shrink; no clipping; no truncation of static copy; sheets move to larger detent.
  • VoiceOver order matches visual order; a row is one element; icon-only controls labelled (Back, Pin, Undo, Keep, Delete, Dismiss); decorative images/islands hidden.
  • Labels + hints per control; states exposed (selected plan, protected pin, count); meaning never color-only (red pairs with trash + "Delete"; green pairs with check + "protected").
  • Touch targets ≥ 44×44 (swipe controls 56; rows 52; nav items 44).
  • Contrast body ≥ 4.5:1, large text + UI ≥ 3:1, light + dark; --fg-2 for small secondary.
  • Reduce Motion: cross-fade, no spring/scale; pressed opacity still; system tokens respected. Reduce Transparency: solid fills for glass. Increase Contrast: stronger separators/secondary. Bold Text respected.
  • No hover; :active pressed state + visible focus ring; gestures have visible alternatives (Undo/Keep/Delete buttons + Review each).
  • Haptics: success on Keep/Pin, warning on Delete, selection on plan, not on scroll.
  • One NavigationStack; no NavigationView; sheet has close + swipe; ContentUnavailableView for empty/error; no Material icons; SF Symbols named.
